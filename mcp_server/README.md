# UniFound MCP Server

This directory contains the dedicated UniFound Model Context Protocol (MCP) Server.

## Architecture
The MCP server provides standard MCP tools to AI Agents without granting direct database access:
- `search_items`
- `get_item`
- `find_matches`
- `get_user_reports`
- `get_claim`
- `create_claim`
- `get_claim_status`
- `get_statistics`

Implemented in Phase 5.
